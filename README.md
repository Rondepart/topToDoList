# Webpack VanillaJS Template
A minimal webpack template for VanillaJS

## Features
- `HtmlWebpackPlugin` for automatic HTML generation from a custom template
- Loaders for CSS (`style-loader`, `css-loader`) and images (`asset/resource`)
- Development server with live reload (`webpack-dev-server`) and source maps (`eval-source-map`)
- Modular configs merged with `webpack-merge`
- Production build with automatic HTML/JS minification


## Getting Started
```bash
npm install
npm run dev  #dev server / src/
npm run build #production build / dist/
```
