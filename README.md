# topToDoList
Project made as part of odin project's curriculum.

## Live demo
[Click here](https://rondepart.github.io/topToDoList/) to view todo list

## Features
- Create, edit, and delete projects
- Create, edit, and delete tasks within a project
- Priority levels (Low / Moderate / High) shown with color-coded task cards
- Due date labels that auto-update
- Data persists across sessions using localStorage

## Built with
- Vanilla JS
- HTML & CSS
- Webpack

## Project Structure
- `todoList.js` - Contains task and project state, CRUD logic, and local storage persistence
- `todoListDOM` - Renders projects and tasks to the DOM
- `todoListController` - Contains event listeners and connects the logic to the DOM
- `index.js` - entry point
